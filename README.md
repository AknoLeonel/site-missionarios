# AHMDF Missionários

Site do projeto social que usa o esporte para transformar vidas em comunidades do DF desde 2018.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://site-missionarios.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Site institucional de uma associação que atende crianças e jovens de comunidades vulneráveis com esporte e cultura. Mostra os projetos, como a Copa Lite, os números de impacto e convida o visitante a apadrinhar.

## Destaques

- Chamada para apadrinhamento em destaque
- Página de projetos e eventos, como a Copa Lite
- Contadores de impacto social
- Animações com Framer Motion

## Tecnologias

Next.js · React · TypeScript · Tailwind CSS · Framer Motion

## Rodando localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
